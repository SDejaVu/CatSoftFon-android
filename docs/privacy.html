Политика конфиденциальности CatSoftFon

Дата последнего обновления: 5 октября 2026 г.

CatSoftFon — SIP-софтфон для Android, позволяющий подключаться к собственной АТС (SIP-серверу), которую вы указываете в настройках приложения самостоятельно. Приложение не принадлежит и не управляется каким-либо конкретным оператором связи — оно работает с любой стандартной SIP-АТС по вашему выбору.

Какие данные приложение обрабатывает

  • Учётные данные SIP-аккаунта (сервер, порт, логин, пароль, отображаемое имя) — вводятся вами и хранятся локально на устройстве. Они передаются только на SIP-сервер, который вы указали, для регистрации и совершения звонков.
  • Контакты и история звонков — создаются и хранятся локально на устройстве, отдельно для каждой из трёх линий. Приложение не читает и не использует системную адресную книгу Android. Если вы включите синхронизацию с каталогом контактов АТС по указанному вами URL, приложение запросит этот адрес и объединит полученные контакты с локальными.
  • Голосовой трафик (аудио) — передаётся в реальном времени только между вами и собеседником через указанный вами SIP-сервер, для обеспечения голосового вызова. Разработчик приложения этот трафик не собирает и не хранит.
  • Технические данные устройства (состояние сети/Wi-Fi, Bluetooth-гарнитура) — используются только на устройстве для правильной работы звонков (выбор аудиоустройства, определение доступности сети) и никуда не передаются.

Чего приложение не делает

  • Не содержит рекламы и SDK для показа рекламы.
  • Не содержит сторонних аналитических или трекинговых SDK.
  • Не передаёт ваши данные разработчику приложения или третьим лицам — единственная сторона, с которой приложение обменивается данными, это SIP-сервер, который вы сами указали в настройках.
  • Не запрашивает доступ к системным контактам, местоположению или камере.

Разрешения приложения и зачем они нужны

  • RECORD_AUDIO, MODIFY_AUDIO_SETTINGS — передача голоса во время звонка и переключение аудиоустройств.
  • INTERNET, ACCESS_NETWORK_STATE, ACCESS_WIFI_STATE — подключение к SIP-серверу по сети.
  • BLUETOOTH, BLUETOOTH_CONNECT — звонки через Bluetooth-гарнитуру.
  • FOREGROUND_SERVICE, FOREGROUND_SERVICE_MICROPHONE, FOREGROUND_SERVICE_PHONE_CALL, WAKE_LOCK — поддержание SIP-регистрации и активного звонка, когда приложение свёрнуто.
  • POST_NOTIFICATIONS, USE_FULL_SCREEN_INTENT, VIBRATE — уведомление о входящем звонке.
  • RECEIVE_BOOT_COMPLETED — автоматическое восстановление SIP-регистрации после перезагрузки устройства (если включено в настройках).

Открытый исходный код

CatSoftFon для Android использует SIP/RTP-движок Linphone SDK (Belledonne Communications), распространяемый по лицензии AGPLv3. В соответствии с этой лицензией полный исходный код приложения открыт и доступен по ссылке «Исходный код» в настройках приложения.

Хранение и удаление данных

Все данные приложения хранятся локально на вашем устройстве. Для их удаления достаточно удалить приложение или очистить его данные в настройках Android.
